## 1. Problem Statement — Who Has the Problem & Why It Matters

### Who Has the Problem?
1. **Bank & Fintech AML / Financial Intelligence Units (FIUs)**: Compliance analysts face **90%–95% false-positive alert rates** from legacy static threshold rules, spending 45–90 minutes per alert manually stitching together transaction spreadsheets without visibility into multi-hop network rings.
2. **Instant Payment & Fraud Operations Teams (RTP, FedNow, UPI, SEPA Instant, P2P)**: Money-mule syndicates receive, split, and forward stolen funds across 3–4 hops in under 60 minutes—long before batch rules trigger.
3. **Legitimate High-Velocity Businesses (SMBs, Payment Collectors, Shared Households)**: Innocent merchants and aggregators frequently exhibit high counterparty fan-in or rapid turnover that triggers crude velocity rules, causing wrongful account freezes.
4. **Scam & Fraud Victims**: Over 90% of authorized push payment (APP) fraud, phishing, and BEC proceeds are cashed out through money-mule networks.

### Why Does It Matter?
- **$800B–$2 Trillion Laundered Annually**: Illicit money-mule networks underpin global cybercrime, human trafficking, and organized fraud.
- **Static Rules Miss Structural Evasion**: Syndicates evade dollar thresholds via *fan-in funnels*, *structuring splitters*, *circular rings*, and *dormant-to-burst takeovers*.
- **Black-Box AI Fails Regulatory Scrutiny**: Regulators (FATF, FinCEN, EU AMLA, OCC SR 11-7) require **calibrated risk scores, human-interpretable feature attributions (TreeSHAP), and traceable network evidence** before an investigator can escalate a case or file a Suspicious Activity Report (SAR).

> **Decision-Support & Synthetic Data Disclaimer**
> - **Investigative Triage Signal Only**: High-risk model predictions, normalized risk scores (0–100), graph indicators, and TreeSHAP attributions are investigative leads to prioritize human review—**not** proof of criminal conduct.
> - **Synthetic Data Environment**: All accounts, transactions, labels, and geographic hub tags generated by this platform are 100% synthetic. Classification performance on synthetic test splits is not evidence of real-world banking performance.

## 2. Solution Overview & Key Capabilities

FlyGuard AI provides a **12-page Financial Intelligence Command Center** backed by a leakage-free machine learning and graph analytics engine:

- **3-Tier Synthetic Behavioral Generator (`20,000` Accounts / `200,000` Transactions)**:
  - **Ordinary Legitimate (~79%)**: Personal P2P, salary/bill cycles, savings, and one-off legitimate spikes.
  - **Difficult Negatives (~15%)**: High-volume SMBs (`hard_negative_smb`), payment collectors (`hard_negative_collector`), shared households (`hard_negative_household`), and cross-border remittances (`hard_negative_remittance`).
  - **Suspicious Money-Mule Archetypes (~6%)**: Rapid pass-through funnels (`mule_rapid_passthrough`), multi-sender fan-in funnels (`mule_fan_in_funnel`), structuring splitters (`mule_fan_out_splitter`), circular rings (`mule_circular_ring`), dormant-to-burst takeovers (`mule_dormant_burst`), and 4-hop layered chains (`mule_layered_chain`).
- **26 Leakage-Free Behavioral, Temporal & Graph Features**:
  - Captures holding-time velocity (`median_holding_time_hours`), rapid forwarding (`rapid_passthrough_ratio`), pass-through symmetry, directed PageRank centrality (`pagerank_score`), and cycle participation (`cycle_participation_score`).
- **Calibrated Multi-Stage Risk Scoring (`0–100` Scale)**:
  - Combines `XGBClassifier` with `SmoothIsotonicCalibrator` on scenario-isolated validation splits (`GroupShuffleSplit`) to map calibrated probabilities onto an actionable 0–100 triage index (`Low < 35`, `Moderate 35–65`, `High 65–85`, `Critical >= 85`).
- **Per-Account TreeSHAP Explainability & What-If Counterfactual Lab**:
  - Computes exact feature attributions for any account and allows investigators to run real-time counterfactual simulations (`POST /api/simulation/what-if`).
- **Interactive Multi-Hop Network Graph & Path Tracer**:
  - Explores 1-to-3 hop ego networks in Cytoscape.js and traces shortest money-laundering paths between suspect accounts (`POST /api/graph/path`).
- **Case Workspace & Secret-Redacting Immutable Audit Trail**:
  - Full alert triage, investigation dossiers, evidence attachment, and compliance audit logging.

## 4. Setup & Installation

### Option A: One-Command Startup (Recommended for Local Evaluation)
```bash
chmod +x scripts/start_all.sh
./scripts/start_all.sh
```

### Option B: Step-by-Step Local Setup

1. **Create & activate virtual environment** (pre-configured in `.venv`):
   ```bash
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   ```
2. **Bootstrap the 20k-account / 200k-transaction dataset & train XGBoost** (pre-populated in `data/flyguard.db`, re-run anytime):
   ```bash
   .venv/bin/python backend/scripts/bootstrap_pipeline.py --accounts 20000 --transactions 200000 --seed 42
   ```
3. **Start the FastAPI Backend (`http://localhost:8000`)**:
   ```bash
   .venv/bin/uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload
   ```
4. **Start the React + Vite Frontend (`http://localhost:5173`)**:
   ```bash
   npm run dev --prefix frontend
   ```

### Option C: Docker Compose
```bash
docker compose up --build -d
```

## 5. Usage Guide ("If-This-Then-That" Operational Matrix)

| IF you want to... | THEN do this in the UI (`http://localhost:5173`)... | OR call this REST API (`http://localhost:8000`)... |
| :--- | :--- | :--- |
| **Monitor overall AML posture & corridor volume** | Open **Overview (`/`)** or **Global Map (`/map`)** | `GET /api/intelligence/overview` · `GET /api/intelligence/map` |
| **Triage high-risk accounts & open alerts** | Open **Flagged Accounts (`/flagged-accounts`)** | `GET /api/accounts?risk_category=Critical` · `GET /api/alerts` |
| **Understand WHY an account was flagged** | Open **Explainable AI (`/explainable-ai`)** | `GET /api/accounts/{account_id}/explain` |
| **Uncover circular mule rings & multi-hop chains** | Open **Network Intelligence (`/network`)** | `GET /api/graph/network/{account_id}?hops=2` |
| **Trace the shortest money flow between two accounts** | Use **Path Tracer** on `/network` | `POST /api/graph/path` |
| **Test counterfactual "What-If" behavioral changes** | Open **What-If Lab (`/what-if`)** & adjust sliders | `POST /api/simulation/what-if` |
| **Open an investigation case & attach evidence** | Open **Investigations (`/investigations`)** | `POST /api/investigations` · `POST /api/investigations/{id}/notes` |
| **Generate new synthetic data or retrain the model** | Open **Settings & ModelOps (`/settings`)** | `POST /api/synthetic/generate` · `POST /api/models/train` |
| **Tune Low / Moderate / High / Critical cutoffs** | Adjust sliders in **Settings & ModelOps (`/settings`)** | `PUT /api/risk/thresholds` |
| **Inspect tamper-evident compliance logs** | Open **Audit Trail (`/audit-trail`)** | `GET /api/audit/logs` |
